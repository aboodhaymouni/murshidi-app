# مُرشِدي | Murshidi

> منصّة إرشاديّة لدعم قرار اختيار التخصّص الجامعي في الأردن — مقدّمة لجائزة وليّ العهد لأفضل تطبيق خدمات حكوميّة، الدورة الخامسة 2026.
>
> **تطبيق مستقلّ.** لا يمثّل وزارة التربية والتعليم ولا وزارة التعليم العالي والبحث العلمي ولا أيّ جهة حكوميّة، ولا يعمل بالشراكة معها. يعتمد على الوثائق التي تنشرها هذه الجهات، ويذكر مصدر كلّ رقم.

- **التقنيّات:** React 19 + TypeScript + Vite 8 + TailwindCSS 3 + Recharts + Capacitor 8 (Android API 23 → 35)
- **اللغة:** العربيّة (RTL) افتراضاً، مع إنجليزيّة كاملة — كلّ نصّ في الواجهة يمرّ عبر قاموس الترجمة
- **الحالة:** 14 شاشة تعمل بالكامل بدون إنترنت بعد التثبيت، بما فيها الخطوط العربيّة المستضافة محليّاً

## الشاشات

الترحيب، الرئيسيّة، **حقلي وكليّاتي**، حاسبة عائد التعليم، مقارنة التخصّصات، مرصد سوق العمل، محاكاة القرار،
اختبار الميول (RIASEC)، تجارب الخرّيجين، الاستشارة الذكيّة، وظائف 2030، المنح، المسارات البديلة، الملفّ الشخصي.

## نظام التوجيهي الجديد

التطبيق مبنيّ على **الخطة الجديدة** لا على فروع ما قبل 2023: يختار الطالب مساره (أكاديمي أو مهني BTEC)
ثمّ حقله أو برنامجه، ويعرض التطبيق بعدها الكليّات التي يفتحها ذلك المسار **بصياغة الوثيقة الرسميّة نفسها**.

الفرق الذي لا يوضّحه غير هذا التطبيق: المسار المهني يؤدّي إلى **الدبلوم المتوسّط والبكالوريوس التقني/التطبيقي**،
وهي درجة مختلفة عن البكالوريوس الأكاديمي — فالطبّ والصيدلة والتمريض والحقوق ليست ضمن قوائمه، بينما علوم
الحاسوب والذكاء الاصطناعي والهندسة المدنيّة والعمارة ضمنها كدرجات تقنيّة. من كان على الخطة القديمة يُعرض له
أنّ الجدول لم يُنشر لفرعه، لا أنّ الأبواب مغلقة أمامه.

النموذج كلّه في `src/lib/tawjihi.ts`، مولّد من `docs/tawjihi-2026-official.json` عبر `npm run tawjihi:gen`،
ومغطّى باختبارات تقارن القوائم بالملفّ المصدر حتى لا ينحرف أحدهما عن الآخر.

## مصادر البيانات

**موثّق ومنسوب لمصدره داخل الشاشة:**

| ما هو | المصدر | نسخة محليّة |
|---|---|---|
| الكليّات المسموح الالتحاق بها لكلّ حقل وبرنامج، 2026/2027 | مجلس التعليم العالي — قرار منشور بتاريخ 8 أيلول 2024 | `docs/sources/mohe-academic-2026-2027.pdf` · `mohe-vocational-2026-2027.pdf` |
| الحدّ الأدنى للالتحاق بكلّ كليّة (90/80/75/70/65 حكومي) | السياسة العامّة للقبول — قرار مجلس التعليم العالي 295/2026 | `docs/sources/admhec-bachelor-policy-2026-2027.pdf` |
| احتساب المعدّل: 30% + 70% من 1000 علامة، للمسارين | تعليمات رقم (12) لسنة 2024، المادّتان (15) و(16) | رابط الجريدة الرسميّة داخل الكود |
| البطالة للربع الثاني 2026 | دائرة الإحصاءات العامّة | — |
| أرقام تقرير مستقبل الوظائف 2025 | المنتدى الاقتصادي العالمي | — |

**توضيحي ويحمل شارة «مثال توضيحي • ليست بيانات رسمية» عند الرقم نفسه:** الرواتب، نسب البطالة لكلّ تخصّص،
أعداد إعلانات الوظائف، معدّلات القبول الاسترشاديّة، مسارات المحاكاة.

**ما لا يدّعيه التطبيق، لأنّه غير صحيح:** أنّ الحدود الدنيا التنافسيّة لعام 2026/2027 قد نُشرت — لم تكن قد
نُشرت وقت الكتابة؛ أنّ شهادة BTEC معتمدة من Ofqual — المنشور مقارنة مرجعيّة عبر ENIC فقط؛ أنّ نسبة من
المقاعد التنافسيّة محجوزة لطلبة المسار المهني — ذلك اقتراح لم يُعتمد.

## التشغيل

```bash
npm install
npm run dev          # خادم التطوير
npm run build        # بناء عادي إلى dist/ (يتضمّن مفتاح الذكاء إن وُجد .env.local)
npm run build:pages  # بناء عام لـ GitHub Pages — يمسح المفتاح ويرفض الإكمال لو تسرّب
npm test             # اختبارات وحدة التوجيهي
npm run tawjihi:gen  # إعادة توليد بيانات التوجيهي من ملفّ المصدر
```

### المستشار الذكيّ

يعمل عبر OpenRouter على `google/gemma-4-31b-it:free`، مع سلسلة بدائل تنتهي بمستشار محليّ يعمل بلا إنترنت،
لأنّ النماذج المجانيّة ترجع 429 من المزوّد المشترك بشكل متكرّر. المفتاح يُقرأ من `.env.local` (غير مُتتبَّع في
git) عبر `VITE_OPENROUTER_KEY`. **لا تضع مفتاحاً في نسخة عامّة** — استخدم `npm run build:pages`، وهو يمنع ذلك.

### بناء Android

```bash
npm run build && npx cap sync android
cd android && ./gradlew assembleDebug
```

> Gradle لا يتعامل مع المسارات العربيّة: أنشئ وصلة (junction) إلى مسار إنجليزي وشغّل `gradlew` منها فقط،
> مع إبقاء `npm run build` و`cap sync` على المسار الأصلي.

**لم تُنشر بعد نسخة APK مبنيّة من هذا الكود.** النسخة الموجودة في صفحة Releases بُنيت في 26 نيسان 2026 تحت
حزمة `jo.mizan.app` وببيانات سابقة لكلّ ما ورد أعلاه — لا تمثّل هذا الكود. اسم الحزمة الحالي
`jo.vcoders.murshidi`، فأيّ بناء جديد يُثبَّت كتطبيق منفصل عن القديم.
