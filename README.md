# مُرشِدي | Murshidi — Source Code (v1.0.0)

> منصّة وطنيّة لدعم قرار اختيار التخصّص الجامعي — مقدّمة لجائزة وليّ العهد لأفضل تطبيق خدمات حكوميّة، الدورة الخامسة 2026.

- **الحزمة:** `jo.mizan.app` — الإصدار `1.0.0`
- **التقنيّات:** React 19 + TypeScript + Vite 8 + TailwindCSS 3 + Capacitor 8 (Android API 23 → 35)
- **اللغة:** العربيّة (RTL)
- **الحالة:** النسخة النهائيّة المسلّمة — تعمل بالكامل بدون إنترنت بعد التثبيت

## التشغيل السريع

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 17 اختبار — يجب أن تنجح كلّها
npm run build      # بناء إنتاجي إلى dist/
```

## بناء نسخة Android

```bash
npm run android:sync
cd android
./gradlew assembleDebug
```

> ملاحظة: Gradle لا يدعم المسارات بأحرف عربيّة — انسخ المشروع إلى مسار إنجليزي قبل البناء (مثل `C:/mizan-build/`).

ملف الإصدار الرسمي الموقّع موجود في صفحة الـ Releases بصيغة APK.

## هيكل المشروع

```
src/
  components/   # مكوّنات مشتركة (تنقّل، ترويسة، شعار)
  data/         # بيانات التخصّصات + لقطة البيانات الرسميّة
  pages/        # 13 شاشة (حاسبة العائد، المقارنة، سوق العمل، الميول، الاستشارة…)
  lib/          # منطق التخطيط
  i18n/         # الترجمات
server/         # خدمة البيانات العامّة (تحديث + تحقّق)
tests/          # اختبارات Node (planning + public-data)
android/        # مشروع Capacitor الأصلي
```
